Past the test. On to the work.

Passing for human was the 1950 question. The question now is what an AI can do for you on an ordinary morning. Claude reads, writes, researches, builds software and works through your own tools, and it keeps going on longer jobs while you get on with your day.

Case study

How this site was made

AI-vs-Turing.com was researched, designed and written with Claude in a single conversation.

  1. Research

    Checked every figure

    Found and read the Turing test study, the AlphaFold Nobel announcement and the Maths Olympiad results, then linked each one as a source.

  2. Design

    Gave it an identity

    Chose the typefaces, colours and the punched-tape motif, which spells TURING in the 5-bit teleprinter code of Turing's era.

  3. Build

    Wrote the code

    Built both pages and the imitation game as plain HTML, CSS and JavaScript that work on phones and in light or dark mode.
